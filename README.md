# NeillCities

> Neill Robson's [Neocities](https://neocities.org/) website source.

## Development

```shell
npm install
npm start # For development server
```

## Publishing

The [Neocities CLI](https://neocities.org/cli) should be installed. It is a Ruby tool that doesn't
exist on NPM.

```shell
npm run build
neocities push dist
```
